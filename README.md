# Customer Churn Analysis

## Project Overview
This project analyzes customer churn data to understand customer behavior and identify factors associated with customers leaving a service.

## Objectives
- Explore and clean customer data
- Perform exploratory data analysis (EDA)
- Analyze churn patterns and customer characteristics
- Create visualizations using Python

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Notebook
Open `Customer_Churn_Analysis.ipynb` to explore the analysis and code.

## Author
Created as a Data Science portfolio project.

## Business Recommendations

- Investigate why customers may be leaving the service.
- Review churn patterns across different customer groups.
- Explore whether contract type and customer tenure are associated with churn.
- Consider retention strategies for customers at higher risk of leaving.

## Limitations

This analysis identifies patterns in customer data. It does not prove that any particular factor causes customer churn.
