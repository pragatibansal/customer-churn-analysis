# Customer Churn Analysis

## Project Overview
This project analyzes customer churn data to understand customer behavior and identify factors associated with customers leaving a service.

## Objectives
- Explore and clean customer data
- Perform exploratory data analysis (EDA)
- Analyze churn patterns and customer characteristics
- Create visualizations using Python

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Notebook
Open `Customer_Churn_Analysis.ipynb` to explore the analysis and code.
